QuizArena

YOUR WEBSITE PACKAGE

Let the learning begin.

Everything you need to connect, publish and host your first classroom game.

1. Create your QuizArena database

Create a separate Supabase project. Open its SQL editor, paste the complete contents of supabase/setup.sql, and run it once. Next run supabase/storage.sql to prepare question-image Storage. Keep your Mathside project separate.

Enable email/password sign-in for teachers and anonymous sign-ins for students in Supabase Authentication. Add your final website address to the Site URL and allowed redirect URLs.

2. Add your public connection details

Open js/config.js in a text editor. Insert the project's HTTPS URL and public publishable/anon key:

window.QUIZARENA_CONFIG = {
  supabaseUrl: 'https://YOUR-PROJECT.supabase.co',
  supabaseAnonKey: 'YOUR-PUBLIC-KEY'
};

Never use a secret or service-role key. Keep the included database policies enabled.

3. Publish the website

  1. Create a GitHub repository for QuizArena.
  2. Upload the contents of this folder, with index.html at the repository root.
  3. Enable GitHub Pages from your branch/root folder in repository Settings → Pages.
  4. Open the HTTPS website and register your teacher account.
  5. Confirm the email if your Supabase settings require it.

No build command is needed. Fonts, images and libraries are bundled locally. To preview locally, run python -m http.server 8000 in this folder and open http://localhost:8000. Do not open index.html as a file URL.

4. Host your first game

  1. Create a quiz with a title, questions, answers, time limits and points.
  2. Preview it, then choose Solo Battle or Team Showdown.
  3. Share the PIN. Join as a student from another browser or device.
  4. Start the game. Try pause, reveal and next.
  5. End the game and export its report.

For Paper Scan, add a class roster in Settings and download the printable cards. Open the same teacher's game on your phone and desktop; use the camera on your phone and Projector view on the desktop.

Paper Scan needs real printed-card testing on Android Chrome and iPhone Safari before classroom scoring. Camera recognition passed synthetic tests, but physical device tests have not been performed.

5. Add it to Teacher Desk

Add a normal link to your deployed QuizArena URL. Open it in a new tab if desired. Do not add an automatic redirect or reuse Mathside's database configuration.

<a href="YOUR-QUIZARENA-HTTPS-URL"
   target="_blank" rel="noopener">Open QuizArena</a>
