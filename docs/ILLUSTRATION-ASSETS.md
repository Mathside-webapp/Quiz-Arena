# QuizArena illustrations

Seven original transparent PNG illustrations generated with the built-in image generation tool for this website. Files live in `assets/illustrations/` and work offline. The hero is reused on welcome, lobby and results screens. Subject art is chosen from the quiz subject; other subjects use the book illustration.
